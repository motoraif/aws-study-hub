⚡ AWS Lambda

Run code without provisioning servers - event-driven, auto-scaling, pay-per-use compute.

Contents

Core Concepts Invocation Types Concurrency & Scaling Features Exam Tips Related

Core Concepts

  • Function - code + runtime + config; event-driven.
  • Limits - 15 min timeout, 128 MB-10 GB memory (CPU scales with it), 512 MB-10 GB /tmp.
  • Package - 50 MB zipped / 250 MB unzipped, or 10 GB container image.

Invocation Types

TypeSource
SynchronousAPI Gateway, ALB
Asynchronous (retries 2x, DLQ)S3, SNS, EventBridge
Poll-based (event source mapping)SQS, Kinesis, DynamoDB Streams

Concurrency & Scaling

  • Reserved concurrency - guarantee/limit for a function.
  • Provisioned concurrency - pre-warmed to avoid cold starts.
  • Default account limit: 1,000 concurrent (soft).

Features

  • Versions & aliases - immutable snapshots + pointers.
  • Layers - shared dependencies.
  • Destinations - route async success/failure.
  • Run in a VPC to reach private resources (RDS).

🎓 Exam Tips

⚠ Frequently tested
  • Max timeout is 15 minutes - long jobs need Fargate, Step Functions, or Batch.
  • S3/SNS invoke Lambda asynchronously with 2 retries; add a DLQ for failures.
  • Provisioned concurrency removes cold starts for latency-sensitive functions.
  • Put Lambda in a VPC to reach private RDS; it needs ENIs and a NAT for internet.
  • CPU scales with memory - raising memory can speed up CPU-bound functions.
