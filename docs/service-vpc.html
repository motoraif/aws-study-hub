🌐 Amazon VPC

Your logically isolated virtual network in AWS - subnets, routing, gateways, and security.

Core Concepts

  • VPC - CIDR block (/16 to /28); regional.
  • Subnets - one AZ each; public (route to IGW) vs private.
  • Route tables - longest-prefix match wins.
  • AWS reserves 5 IPs per subnet.

Gateways & Routing

  • Internet Gateway - inbound + outbound for public subnets.
  • NAT Gateway - outbound-only for private subnets (IPv4).
  • Egress-Only IGW - outbound-only for IPv6.
  • VPC Endpoints - Gateway (S3/DynamoDB) and Interface (PrivateLink).

Security Groups vs NACLs

Security Group

  • Instance/ENI level
  • Stateful
  • Allow rules only

Network ACL

  • Subnet level
  • Stateless (open ephemeral ports)
  • Allow + Deny, ordered

Connectivity

  • VPC Peering - 1:1, non-transitive.
  • Transit Gateway - hub-and-spoke, transitive.
  • PrivateLink - expose a service privately (works with overlapping CIDRs).
  • Site-to-Site VPN / Direct Connect - hybrid.

🎓 Exam Tips

⚠ Frequently tested
  • Public subnet = has a route 0.0.0.0/0 to an IGW; nothing else makes it public.
  • NACLs are stateless - you must allow ephemeral ports (1024-65535) for return traffic.
  • VPC Peering is NOT transitive; use Transit Gateway for any-to-any at scale.
  • Gateway Endpoints (S3/DynamoDB) are free; Interface Endpoints cost per hour + data.
  • Overlapping CIDRs block peering/TGW - use PrivateLink to share a specific service.
