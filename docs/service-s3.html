📦 Amazon S3

Object storage built for 11 nines of durability - the backbone of data lakes, static sites, backups, and content delivery.

Contents

Core Concepts Storage Classes Security Key Features Exam Tips Related

Core Concepts

  • Buckets - globally unique names; region-scoped.
  • Objects - up to 5 TB; key + value + metadata.
  • Durability - 99.999999999% (11 nines) across multiple AZs.
  • Consistency - strong read-after-write for all operations.

Security

  • Block Public Access - on by default; overrides ACLs/policies.
  • Bucket policies vs IAM policies vs ACLs (legacy).
  • Pre-signed URLs - time-limited access to private objects.
  • Encryption: SSE-S3, SSE-KMS, SSE-C, or client-side.
  • VPC Gateway Endpoint - private access, no internet.

Key Features

  • Versioning - keep every version; protects against overwrite/delete.
  • Lifecycle rules - transition to cheaper classes or expire.
  • Replication - CRR (cross-region) / SRR (same-region).
  • Event notifications - to Lambda, SQS, SNS, EventBridge.
  • Static website hosting; front with CloudFront + OAC.
  • Object Lock - WORM for compliance.

🎓 Exam Tips

⚠ Frequently tested
  • Block Public Access overrides any bucket policy or ACL that grants public access.
  • Use OAC (not the legacy OAI) to let only CloudFront read a private bucket.
  • Pre-signed URLs grant temporary access without changing bucket permissions.
  • SSE-KMS adds audit trails and key control; SSE-S3 is the simplest default.
  • Use a Gateway VPC Endpoint for S3 (free) to keep traffic off the internet.
