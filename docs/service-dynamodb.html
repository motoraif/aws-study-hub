⚖️ Amazon DynamoDB

Fully managed NoSQL key-value and document database with single-digit millisecond latency at any scale.

Contents

Core Concepts Indexes Capacity & Performance Features Exam Tips Related

Core Concepts

  • Table - items (rows) with attributes; schemaless beyond keys.
  • Partition key (simple) or partition + sort key (composite).
  • Single-digit ms latency; virtually unlimited scale.

Indexes

GSI

  • Different partition key
  • Add anytime
  • Eventually consistent

LSI

  • Same partition, different sort key
  • Only at table creation
  • Strongly consistent option

Capacity & Performance

  • On-demand - pay per request; unpredictable traffic.
  • Provisioned - set RCU/WCU; auto scaling available.
  • DAX - in-memory cache; microsecond reads.
  • Reads: eventually (cheap) vs strongly consistent.

Features

  • Streams - ordered change log; trigger Lambda.
  • TTL - auto-expire items (free).
  • Transactions - ACID across items/tables.
  • Global Tables - multi-region active-active.

🎓 Exam Tips

⚠ Frequently tested
  • Choose a partition key with high cardinality to avoid hot partitions.
  • GSI = different partition key, added anytime; LSI = at creation only.
  • Use on-demand capacity for spiky/unknown traffic; provisioned for steady.
  • DAX gives microsecond reads for read-heavy, repeated-key workloads.
  • Global Tables provide multi-region active-active replication.
